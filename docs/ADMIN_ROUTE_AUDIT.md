# Admin route audit

Date: 2026-11-17. Primary checklist: owner-supplied Admin Backend Roadmap PDF.

Reconciliation, classrooms/routines, login policies, permission roles, General Settings, calendar/catalogs, student/guardian/enrollment/student/staff attendance and files/attachments/study materials/notices/events are applied after explicit approvals and PostgreSQL-tested. Library and Inventory migrations were checked against actual PostgreSQL history, applied using the previously approved revised SQL, and PostgreSQL acceptance passed 8/8. Homework/lesson planning is APPLIED and PostgreSQL accepted 7/7. Conduct, staff leave and Admin-recorded teacher evaluations are APPLIED and PostgreSQL accepted 10/10, including multi-connection write serialization and rollback safeguards. Examination operations are APPLIED and PostgreSQL acceptance passed 8/8. Fees/accounts/payroll/wallet/reporting operations are APPLIED; PostgreSQL acceptance/concurrency passed 11/11. Online examinations/front-office/dormitory operations are APPLIED and PostgreSQL-tested. Certificate/ID migration is applied and PostgreSQL/full-stack/browser acceptance passes. Nine configuration profiles now use guarded APIs but remain separately migration-gated. The dashboard reads existing persisted data without schema changes.

183 Admin pages inspected, including local import graphs and centralized API contracts. Sidebar links identify navigation evidence only; unlinked pages remain in scope. No route is considered complete merely because a page or API exists.

Database: 31 migrations and 106 public tables including history, verified against actual PostgreSQL. Document Issuance is applied. All 99 original application tables and 30 prior history entries were preserved before and after its commit. Full-stack fixtures rolled back with all 106 table hashes unchanged. Admin Configuration is drafted only; no future migration was applied.
